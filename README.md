# 🎬 StreamFlix

StreamFlix is a Netflix-inspired movie browsing web app built with React, Vite, Tailwind CSS, and TMDB API.

## 🚀 Live Demo

Add your Vercel link here.

## ✨ Features

- Browse trending movies
- Search movies using TMDB API
- View movie details
- Watch trailers
- Add movies to My List
- Genre filter
- Loading skeleton UI
- Responsive Netflix-style design

## 🛠 Tech Stack

- React
- Vite
- Tailwind CSS
- React Router DOM
- TMDB API
- Local Storage
- Vercel

## 📌 Project Purpose

This project was built for learning React, API integration, routing, state management, and deployment.
- Firebase Authentication
- Login and Signup
- Protected My List route
- Logout functionality
